# codejs

A personal learning workspace for JavaScript and TypeScript experiments.

TypeScript is the default language for everything in this repo. `.js` files
only appear where the point is to demonstrate a specific JS language version.

See [CONVENTIONS.md](./CONVENTIONS.md) for coding rules, file layout, and
the do-not-touch list.

## Quick start

```bash
nvm use
npm install
npm run typecheck
npm test
```
