# TypeScript experiments

Generics, decorators, conditional types, mapped types, and other
type-system features.

`generics.ts` demonstrates constrained generics (`pluck`), conditional
types (`IsArray`, `ElementOf`), and mapped types (`ReadonlyDeep`, `Optional`).

Run it: `npx tsx src/ts/generics.ts`
Run tests: `npx vitest run src/ts`
